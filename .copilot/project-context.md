# SmartAssess AI

## Overview

SmartAssess AI is an adaptive AI-powered interview intelligence platform.

## Users

- Students
- Recruiters
- Colleges

## Core Modules

- Authentication
- Resume Analysis
- AI Interview
- Resume Parser
- Voice Analysis
- Face Analysis
- Semantic Evaluation
- Dashboard
- Reports

## Goal

Build an industry-grade interview intelligence platform using FastAPI, Next.js, PostgreSQL and AI.
